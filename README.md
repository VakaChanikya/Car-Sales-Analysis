# Car-Sales-Analysis
This project presents an interactive Car Sales Analysis Dashboard built using Microsoft Power BI.
The goal of the project is to analyze sales performance, customer behavior, and product trends in an automobile dealership using historical sales data.

The dashboard helps stakeholders understand which cars sell the most, who buys them, when sales peak, and how revenue changes over time, enabling data-driven business decisions.

🎯 Business Problem

Car dealerships generate large volumes of sales data every day.
However, without proper analysis it becomes difficult to answer important questions such as:

Which car brands generate the highest revenue?

Which months have peak sales?

Which regions perform better?

Which car models are underperforming?

This project solves the above problems by transforming raw data into meaningful insights using data visualization and analytics.
